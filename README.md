# お米のねだんのひみつ　値札をOPEN！

特別支援学校・高等部1年の社会科授業用Webアプリです。

## 目的

単元「スーパーの秘密を探れ！―お米が売り場に届くまで―」で、3種類のお米について、値段の予想、産地・距離の確認、値札の1つずつの公開、距離順位と価格順位の比較を行います。

本時では「遠さだけでは値段は決まらない」ことへの気付きを中心にし、価格の理由をアプリ内で断定・説明しません。

## 基本機能

- 商品は3種類固定
- 「高いと思う順」にタップして予想
- 学校から近い順を表示
- 値札を1商品ずつOPEN
- 「学校から近い順」と「値段が高い順」を比較
- 「遠いお米ほど、高い？」を考える
- 「ほかに何がかんけいしているんだろう？」で終了
- ふりがなON/OFF
- 「最初から」で授業進行だけをリセット

## 商品画像について

商品画像を掲載・登録する機能はありません。商品名、産地、品種、重さ、価格、距離情報だけで構成しています。

## 先生モード

画面最下部の「先生モード」から、3商品それぞれについて以下を変更できます。

- 商品名
- 商品名のよみ
- 産地
- 産地のよみ
- 品種
- 品種のよみ
- 重さ
- 価格
- 学校からの距離表示
- 学校から近い順（1〜3）

「設定を保存する」を押すと、その端末の `localStorage` に保存します。

## 配布用URL

先生モードで任意の設定を入力したあと「配布用URLを作る」を押すと、その時点の3商品の設定をURLの `#cfg=` 部分に保存したURLを作成します。

配布URLに含まれるもの：

- 商品名・よみ
- 産地・よみ
- 品種・よみ
- 重さ
- 価格
- 距離表示
- 距離順位

配布URLに含まれないもの：

- 生徒の予想
- OPENした値札
- 比較画面の進行状況

そのため、同じ配布URLをロイロノートで複数の生徒に配っても、全員が同じ商品設定の初期状態からそれぞれ操作できます。

### 注意

`index.html` を端末内から `file://` で開いて作ったURLは、他の端末には配布できません。

GitHub Pages / Cloudflare Pagesなどで公開した `https://...` のWebアプリを開き、そこで先生モードから「配布用URLを作る」を実行してください。

外部APIやデータベースは使用していません。設定情報そのものがURL内に入ります。

## 保存・リセット

- 先生モードの商品設定：`localStorage`
- 授業中の予想・OPEN状況：`sessionStorage`
- 配布設定：配布URL内の `#cfg=`
- 「最初から」：予想・OPEN状況・比較だけをリセット
